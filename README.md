# TiFcifre

Joc românesc de numărat pentru copii: copilul numără obiectele și alege cifra corectă. Include niveluri 1–5, 1–10 și 1–20, răspunsuri mari pentru touch, contoare pentru corecte/greșite și feedback audio/vizual.
